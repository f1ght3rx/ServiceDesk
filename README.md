# Service Desk — Система заявок в техническую поддержку

Веб-приложение для регистрации и отслеживания обращений в техническую поддержку. Разработано в рамках практической работы по теме «Проектирование и программная реализация пользовательского интерфейса информационной системы».

## 📋 Возможности

- **Авторизация и регистрация** по email и паролю (Supabase Auth).
- **Создание заявок**: тема, категория, описание, приоритет.
- **Ролевая модель**:
  - *Пользователь* — видит только свои заявки и не может менять их статус.
  - *Администратор* — видит все заявки, может фильтровать по статусу и переводить их в работе/закрывать.
- **Разграничение доступа (RLS)** на уровне базы данных: попытки изменить чужие данные через API блокируются PostgreSQL.
- **Валидация формы** и состояния загрузки на клиенте.
- **Уведомления** об успехе, ошибках и подтверждение необратимых действий.

## 🛠️ Технологический стек

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (без фреймворков).
- **Backend / База данных:** Supabase (PostgreSQL).
- **Безопасность:** Supabase Auth (JWT) + Row Level Security (RLS).

## 🚀 Запуск проекта

### 1. Настройка Supabase
1. Создайте проект на [supabase.com](https://supabase.com).
2. В панели Supabase откройте **SQL Editor** и выполните скрипты для создания таблиц `profiles`, `requests`, триггеров и политик безопасности RLS *(скрипты находятся в документации к работе)*.
3. Перейдите в **Project Settings → API** и скопируйте `Project URL` и `anon public key`.

### 2. Настройка фронтенда
1. Откройте файл `index.html`.
2. Вставьте свои ключи в блок конфигурации перед подключением `app.js`:
